# To-Do List Web App

A lightweight to-do list web application built with vanilla HTML, CSS, and JavaScript. Tasks are stored locally in your browser so you can keep track of your work between visits.

## Features

- Add tasks with a simple form
- Toggle tasks as completed
- Filter tasks by all, active, or completed
- Remove tasks individually or clear all completed tasks at once
- Tasks persist locally using `localStorage`

## Getting Started

1. Open `index.html` in your browser.
2. Add tasks using the input box and "Add" button.
3. Use the filter controls to see specific task groups or clear completed items.

## Development

All of the logic lives in `app.js`, with styling handled by `styles.css`. No additional tooling or dependencies are required.
